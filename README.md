# Rangkuman Materi: Git, GitHub, dan Markdown

Repository ini dibuat untuk menyimpan dokumen rangkuman serta catatan pembelajaran mengenai **Git**, **GitHub**, dan **Markdown**.

## 📌 Isi Repository

- **`rangkuman.txt`** : File utama yang berisi rangkuman lengkap materi mengenai:
  - Konsep & dasar-dasar **Version Control Systems (VCS)** dan **Git**.
  - Perintah-perintah dasar Git (inisialisasi, staging, commit, branching, reset).
  - Penggunaan **GitHub** dan pengelolaan *remote repository*.
  - Panduan sintaksis dasar penyusunan dokumen menggunakan **Markdown** (`.md`).
- **`README.md`** : File dokumentasi dan penjelasan singkat mengenai isi repository ini.
